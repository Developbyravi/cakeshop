# Sweet Cravings - Bakery Website

A beautiful, responsive website for a premium cake and pastry shop featuring an elegant design with cream, pink, and chocolate color scheme.

## Features

- **Responsive Design** - Works seamlessly on desktop, tablet, and mobile devices
- **Multiple Pages** - Home, Menu, About, and Contact pages
- **Shopping Cart** - Fully functional cart with localStorage persistence
- **Product Showcase** - Beautiful product cards with hover effects
- **Customer Testimonials** - Social proof section
- **Instagram Gallery** - Visual content integration
- **Contact Form** - Easy way for customers to get in touch
- **Mobile Navigation** - Hamburger menu for mobile devices

## Pages

### Home (index.html)
- Hero section with call-to-action buttons
- Featured signature cakes
- Why choose us section
- Customer testimonials
- Instagram gallery
- Footer with contact info and social links

### Menu (menu.html)
- Signature cakes collection
- Cupcakes section
- Product cards with ratings and prices
- Add to cart functionality

### About (about.html)
- Company story and mission
- Core values
- Team member profiles

### Contact (contact.html)
- Contact form
- Business information (address, phone, email)

## Technologies Used

- HTML5
- CSS3 (Custom properties, Grid, Flexbox)
- JavaScript (ES6+)
- Font Awesome Icons
- Google Fonts (Playfair Display, Poppins)
- Unsplash Images

## Cart Functionality

The shopping cart includes:
- Add items from any product page
- View cart modal with all items
- Increase/decrease quantities
- Remove individual items
- Clear entire cart
- Real-time total calculation
- Persistent storage (localStorage)
- Cart count badge in navigation

2. Open `index.html` in your web browser
3. No build process or dependencies required!
